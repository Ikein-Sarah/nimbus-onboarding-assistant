# Glossary of Internal Terms

Last updated by: whoever notices a gap — this is a living doc, edit it
directly rather than asking someone else to.

If you hear a term in a meeting and don't know what it means, it's
probably here. If it's not, add it, don't just guess and nod.

## Company-wide

| Term | Meaning |
|---|---|
| NL | Nimbus Labs, used constantly in Slack, rarely in docs |
| Flow | Short name for the product, Nimbus Flow, after first mention (see `growth/brand-guidelines.md`) |
| Anchor day | The one shared in-office day a co-located team agrees on, see `hybrid-work-policy.md` |
| Sev1 / Sev2 / Sev3 | Incident severity levels, see `engineering/oncall-rotation.md` |
| PIP | Performance improvement plan — not currently documented anywhere formally, ask People if it comes up |
| RCA | Root cause analysis, the core section of a postmortem |
| ATS | Applicant tracking system, referenced in `people/hiring-process.md` |

## Engineering

| Term | Meaning |
|---|---|
| Monorepo | The single repo at github.com/nimbuslabs/platform, see `engineering/dev-environment-setup.md` |
| Canary | A small-percentage rollout used to catch bad deploys early, see `engineering/deployment-process-v2.md` |
| Freeze window | A period where production deploys are blocked, usually around a big customer launch |
| Tech lead | Currently John Adeyemi for the core platform team — not a formal title change, just a role |
| Runbook | A step-by-step doc for handling a known operational task, e.g. `engineering/runbook-database-failover.md` |

## Growth

| Term | Meaning |
|---|---|
| ICP | Ideal customer profile — mid-sized logistics companies, per the handbook's company description |
| CAC | Customer acquisition cost |
| MQL / SQL | Marketing-qualified lead / sales-qualified lead — used in CRM reporting, not defined in `growth/crm-rules.md` itself, just assumed knowledge |
| Brief | The one-page campaign proposal doc, see `growth/campaign-process.md` |

## Finance

| Term | Meaning |
|---|---|
| Envelope | A department's spending allocation for the year, see `finance/budget-planning.md` |
| Net 30 | Payment due 30 days after invoice, the default vendor term |
| Burn | Monthly cash spend — comes up in forecasting conversations, not formally defined in any finance doc yet |
| Variance | The gap between forecast and actual spend, see `finance/budget-planning.md` |

## People

| Term | Meaning |
|---|---|
| Calibration | The cross-manager process that makes performance ratings consistent, see `people/performance-review-cycle-2026.md` |
| Band | A salary range for a level, see `people/salary-bands.md` |
| Scorecard | The structured interview feedback form, see `people/hiring-process.md` |

## Things people ask about that are NOT internal terms

A few things come up in questions that sound like they should be glossary
entries but aren't real Nimbus Labs terms because we don't have the
underlying program: stock options, equity, a pension scheme. If someone
asks what "the ESOP" means, the answer is that we don't have one — see
`faq.md`.
