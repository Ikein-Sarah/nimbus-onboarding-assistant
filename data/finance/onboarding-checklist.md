# Finance Onboarding Checklist

Last updated by: henrik@nimbuslabs.io

Pair with `general/new-hire-first-week.md`. Finance access takes slightly
longer to provision than other departments because of the banking portal
review step below — plan around that.

## Week 1

- [ ] Get accounting system access and expense tool admin access (should
      be automatic per `general/tooling-and-access-requests.md`)
- [ ] Get banking portal **view** access — payment initiation access is
      requested separately and requires Henrik's direct sign-off, it is
      not part of standard onboarding
- [ ] Read `expense-policy.md`, `procurement-approvals.md`, and
      `budget-planning.md` in that order — later docs assume you already
      know the approval matrix from procurement-approvals
- [ ] Shadow a reimbursement run to see the expense process end to end

## Week 2

- [ ] Shadow a vendor onboarding using `vendor-payment-runbook.md`
- [ ] Sit in on a budget variance review if the timing lines up with the
      monthly forecast cycle (`budget-planning.md`)
- [ ] Understand the department envelope structure — ask Henrik to walk
      through the current year's envelopes by department, this isn't
      written down anywhere in a way that stays current

## Things that are easy to miss

- The home office stipend (`general/hybrid-work-policy.md`) is tagged
  "home office" in the expense tool, not "equipment" — reimbursements
  get miscategorized if you don't know this.
- Paid media invoices (`growth/paid-media-policy.md`) are reconciled
  monthly and don't go through the normal expense claim flow — don't
  process one as a personal reimbursement by mistake.
- Growth's campaign budget approvals (`growth/campaign-process.md`) and
  paid media approvals (`growth/paid-media-policy.md`) use different
  thresholds. New Finance hires sometimes apply the wrong one when
  reviewing a request — check which type of spend it actually is first.
