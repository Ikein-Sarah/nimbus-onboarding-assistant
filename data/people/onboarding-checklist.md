# People Onboarding Checklist

Last updated by: tunde@nimbuslabs.io

This doc does double duty: it's the checklist for a new People team
member's own onboarding, and it documents the checklist People runs for
*every* new joiner company-wide. Sections are labeled accordingly.

## For a new People team member

- [ ] Get Workday admin access and applicant tracking system access (see
      `general/tooling-and-access-requests.md` for the standard table)
- [ ] Shadow an offer approval end to end, referencing
      `hiring-process.md`
- [ ] Get walked through `salary-bands.md` and how placement decisions
      get made — this is sensitive, don't discuss specifics with anyone
      outside People until you've done this walkthrough
- [ ] Shadow a review calibration session if the timing lines up with
      `performance-review-cycle-2026.md`'s cadence

## What People runs for every new joiner (reference, not just for People hires)

This is the checklist behind `general/new-hire-first-week.md` — the parts
People specifically owns:

1. Send offer letter and start date confirmation, generate the personal
   folder record.
2. Kick off IT provisioning request (email, Slack, Workday, Google
   Workspace) at least 3 working days before start date.
3. Confirm manager has assigned an onboarding buddy.
4. Day 1: welcome email with links to `code-of-conduct.md`,
   `employee-handbook.md`, and `new-hire-first-week.md`.
5. Week 4: send the monthly new-joiner cohort call invite.
6. Day 90: trigger first formal review scheduling per
   `performance-review-cycle-2026.md`, and confirm on-call rotation
   eligibility for engineering joiners per
   `engineering/oncall-rotation.md`.

## Common gaps (People-side, not the new joiner's fault)

- IT provisioning requests sent late, causing a rocky day 1. Target is 3
  working days ahead, but this slips more often than it should when a
  start date is confirmed late.
- Offer letters occasionally reference an old salary band version if
  drafted right before the annual January band review. Double-check the
  band is current before sending.
